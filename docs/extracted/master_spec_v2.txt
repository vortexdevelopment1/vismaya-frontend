1. Product Definition
Vismaya Creative Studios is an IMDb-inspired professional identity, portfolio, discovery and opportunity platform for aspiring, emerging and experienced creative talent. Unlike IMDb, Vismaya does not rely on project pages as the primary database object. The central object is the talent profile: identity, portfolio, work experience, skills, verification and discoverability.
CORE PRODUCT LOOP
Create Identity  ->  Build Portfolio  ->  Become Discoverable  ->  Apply / Get Shortlisted  ->  Audition  ->  Get Selected  ->  Build Work Record
Pillar
Definition
Professional Identity
Every talent can build a persistent Vismaya identity, including aspiring talent with zero professional credits.
Talent Database
Searchable talent profiles organized by profession, department, designation, specialization and skills.
Portfolio & Work Record
Featured work, profession-specific media, work experience, training, skills and professional evidence.
Industry Discovery
Verified industry organizations can search, preview, spend profile-view credits, favourite and shortlist talent.
Opportunity Workflow
Vismaya-controlled opportunity submission, applications, screening, audition/self-tape and selection.
Trust Layer
Identity verification, professional verification, content moderation, opportunity approval and admin audit controls.

Decision precedence: where earlier planning rounds conflict with later rounds, the latest explicit user decision in this project is the source of truth.

49. Critical Business Rules for Development
One login and one universal Vismaya identity per user.
A Talent account has one active top-level category: Open Talent OR Film & TV. Migration between them is admin-only.
Open Talent allows one primary profession plus up to 3 secondary professions.
Film & TV uses Department -> Designation -> Specialization; up to 2 secondary departments can be added later.
Talent becomes searchable only after successful payment and >=60% weighted profile completion.
Talent can apply only after the same minimum completion threshold.
No direct messaging/chat between talent and industry anywhere in the product.
Contact information, remuneration and physical attributes must never be exposed through ordinary profile APIs.
Every opportunity requires Vismaya review before publication.
Every full industry profile view must be transactionally charged against the organization credit ledger unless covered by the 7-day repeat-view window.
Search results and limited preview never consume industry credits.
All sensitive or critical admin/user changes require audit logging where applicable.
Portfolio uploads should pass technical validation and automated moderation before escalation to admin where required.
Profession taxonomies should be configuration-driven, not hard-coded into frontend logic.
Exact professional URLs should resolve duplicates using Vismaya ID only when necessary.
