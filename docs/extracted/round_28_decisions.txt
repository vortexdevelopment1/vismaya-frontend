Workflow Principle

Current Vismaya Opportunity Architecture
Organization → Project → Opportunity → Vismaya Review → Publication → Applications → Screening →
Shortlisting → Audition/Interview → Selection → Project Completion
Immediate Actions / Locked Rules
1. Every opportunity is tied to a project.
2. Vismaya approves every opportunity before publication.
3. Talent applies only through Vismaya.
4. Organizations handle applicant screening and shortlisting.
5. Auditions/interviews and self-tapes can run through Vismaya.

6. Talent can withdraw an application at any time.
7. Organization cancellation requires a Vismaya request.
8. Deadlines are mandatory and opportunities close automatically.
9. Selection and project completion are recorded on the platform.
